# DataAsk 企业控制台界面规范

参考腾讯 TDesign 的企业级后台信息层级与控制方式（仅借鉴视觉和交互规范，仍使用 Vue 3 + Vant，不引入新 UI 框架）。

## PC 统一规格

| 项目 | 约定 |
| --- | --- |
| 主色 | #0052D9（TDesign 风格蓝） |
| 默认按钮、输入框、下拉框 | 高度 32px，字号 13px，圆角 4px |
| 操作层次 | 主按钮：蓝底白字；次按钮：白底灰边；危险操作：红字；列表行：文字链接 |
| 搜索区域 | 左侧筛选项、查询与重置；右侧新增 / 刷新 / 批量操作，控件间距 8–10px |
| 列表 | 40px 表头、44px 行高、浅灰分隔线、鼠标悬停淡底色 |
| 分页 | 默认每页 10 条，提供 10/20/50/100 条、上一页/下一页、当前页和总条数 |
| 返回按钮 | 左箭头 + “返回…”文字，使用同一二级按钮尺寸（32px） |
| 弹窗 | 标题与表单明确分层，底部操作右对齐，取消为次按钮、保存为主按钮 |
| 焦点 | 清晰的 2px 轮廓和输入框焦点反馈，支持键盘操作 |

## 影响范围

- `src/tdesign-console.css`：统一 tokens、按钮、筛选、列表、分页、弹窗、暗色主题；桌面样式限定 1024px 以上
- `src/components/RecordList.vue`：查询/重置/刷新及额外筛选插槽分区
- `src/components/ListPagination.vue`：统一 10 条默认分页与文案
- `src/components/AdminAuditLog.vue`：审计列表与分页对齐
- `src/App.vue`：我的图表筛选由点击查询后应用、统一详情页及系统管理返回按钮
- `public/miniapp/index.html`：H5 列表、返回、按钮和弹窗的扁平化样式，不变更业务逻辑
- 数据源、用户维护弹窗只统一样式，不修改数据接口

## 回归

在已有项目依赖与浏览器环境中执行：

```bash
cd web
npm ci
npm run build
npm run preview -- --host 127.0.0.1 --port 4175
# 在另一个终端执行，管理界面测试默认使用 4175
npm run test:management
# 其余脚本默认使用 4173，可以通过 DATAASK_UI_URL 设置 URL
DATAASK_UI_URL=http://127.0.0.1:4175 npm run test:layout
DATAASK_UI_URL=http://127.0.0.1:4175 npm run test:audit
DATAASK_UI_URL=http://127.0.0.1:4175 npm run test:pc
```

注意：默认端口分别由各自脚本定义，避免把 `npm run test:management` 运行在 4173 上导致连接失败。

## 模型配置统一管理

系统管理现在只保留一个「模型配置」入口，同时显示对话模型（Base URL、模型 ID、API Key）
与 Embedding（启用、Base URL、模型 ID、向量维度、API Key）。两组模型分别测试与保存，
Embedding 的语义索引在本页查看与重建。

配置继续写入原有的 `/api/admin/settings/ai` 与 `/api/admin/settings/embedding`，
**不迁移数据库配置、不重置已保存密钥**。每次修改 API Key 时留空可保留原密钥，明确
选择“清除原有 API Key”后必须确认。Embedding 不启用时不会阻止对话模型正常配置。
手机端采用同一设置组件的窄屏布局。

回归验证：`npm run test:admin`，覆盖模型页面合并、密钥清除保护、两类模型各自测试和
保存，以及语义索引重建。

### 模型配置折叠与铺满布局

- 模型页独占主内容区，不再套用其它管理页的居中卡片宽度、外边距或背景间隙。
- 「对话模型」与「Embedding 模型」默认收起，只显示标题、用途与配置状态。
- 点击标题行展开，点击再次收起；两个区域的展开状态互不影响，展开/收起不会保存配置或改变 Embedding 的启用状态。
- 每个折叠区域保留原有测试连接、保存、API Key 安全确认、语义索引重建操作。
- PC 管理页端到端回归脚本检查默认收起、独立展开、无外层间隙及配置接口。

### 全站铺满与提示居中（PC）

- 所有登录后的 PC 内容区均取消最大宽度及外层灰底间隙：工作台、问数、我的图表、历史会话、数据源、模型、ADS 授权、指标、用户、配置状态与审计。
- 保留表单、列表和工具栏必要的内部排版留白，不改变导航栏宽度、登录页或弹窗安全边距。
- 模型配置移除单独的说明横幅，第一行直接是对话模型折叠标题，刷新按钮移至系统管理现有标题栏。
- Vant 通用 Toast（成功、失败、普通提示）改为视口水平与垂直正中，深浅色样式继续使用原有主题变量。
- 管理页面/模型页面浏览器回归增加铺满、提示位置和横幅不存在的检查。


### 所有页面取消顶部重复横幅

- PC 每个页面**只保留全局 48px 导航条中的面包屑**作为页面名称和层级，不再在正文重复绘制「工作台」「智能问数」「我的图表」「历史会话」或管理子页面的标题/说明横幅。
- 系统管理的返回、模型刷新、配置状态刷新、ADS 表刷新/数据源配置及图表详情的返回、刷新、共享、取消收藏均移到导航条右侧工具区，保留原权限和操作行为。
- ADS 表授权、配置状态、指标导入页也删除重复的内层标题条；查询筛选、列表以及表单仍保留清晰分组与必要的内部间距。
- 手机端保留移动导航和交互必要的欢迎/操作区域（不属于 PC 页面的重复横幅），不改变问数功能、底部弹层或已有权限。
- 浏览器回归断言改为无重复标题横幅、页面紧贴导航区、导航标题可识别、返回操作可用；不再要求旧标题条存在。


### 登录页视觉（2026-11-21）

PC 登录页按确认稿调整为全屏左右布局：左侧为 DataAsk 品牌、自然语言问数主文案、四项能力说明及纯 CSS 数据分析插画；右侧为半透明白色登录卡片。
保留现有 `/api/auth/login` 接口、账号密码字段、密码显隐、Enter 登录、loading 状态和移动端登录逻辑，不将任何凭证写入视觉层。
登录页插画使用 HTML/CSS，不依赖外部图片或 CDN，便于离线部署和后续主题调整。


### 登录页 1:1 校准（目标稿 image 2）

- PC 登录页主要元素按 1692×930 目标稿比例绝对定位，不再依赖 6:4 栅格自动分配。
- 中央 3D 数据分析装置直接使用目标稿裁剪出的项目内 WebP 资源 `/login-hero.webp`，替代上一版 CSS 仿制插画。
- Logo、主标题、说明、四项能力、登录卡片、顶部安全提示、版权位置均按照目标稿百分比坐标校准。
- 登录卡片继续是真实 Vue/Vant 表单，不把账号密码做进图片；因此登录、Enter、密码显隐和 loading 状态保持不变。


### 登录页融合调整（2026-11-21）

- 移除登录页右上角“内部系统 · 安全登录”及绿色状态点。
- 中央 3D 分析装置放大并向左延展，与主文案区域产生视觉关联；右侧登录卡片略向左收拢，减少三段式割裂。
- 背景增加跨越文案、插画与登录卡片的连续蓝色光晕，卡片左侧阴影更轻。
- 登录接口、账号密码控件、密码显隐、Enter 登录和移动端页面均不变。


### 登录页场景融合二次校准

- 3D 插画不再以矩形图片边界直接显示：图片增加四边渐隐遮罩与 multiply 混合模式，浅蓝底色自然融入整页背景。
- 插画按目标稿缩小、下移，避免压迫标题与登录卡片；卡片宽度/阴影也回收到目标稿比例。
- 整页背景改为连续蓝白光场，底部蓝色波浪与白色前景波浪重新按目标稿调整，让左右两侧均保留蓝色层次。
- Chrome 自动填充账号/密码时强制保持登录表单白色背景，避免出现突兀的蓝色 autofill 色块。


### 登录页 3D 插画透明化

- 中央 3D 图不再使用 `login-hero.webp` 位图。上一版的浅蓝矩形底色即使加 mask / multiply 仍会产生贴图边界，因此改为内联透明 SVG 场景。
- SVG 直接绘制浏览器问数窗口、柱状图、环形图、聊天气泡、数据库和立体底座，所有元素背景透明，页面蓝白光场会自然从图形间透出。
- 删除 raster hero 的 multiply 和四边 mask 补救逻辑；只保留柔和外部光晕与 SVG 自身阴影。
- 原 `web/public/login-hero.webp` 暂不删除以避免历史构建缓存异常，但当前登录页面已不再引用它。


### 登录页局部方向与右上角颜色调整

- 中央 3D 问数窗口由原来的 `rotate(-7)` 反向为 `rotate(7)`，按确认效果向左倾斜。
- 登录卡片右上角保留双层圆弧，但增强蓝色渐变饱和度与内层浅蓝描边，让“欢迎登录”区域右上角更有层次。
- 不修改整体布局、登录逻辑、密码控件、移动端样式或“内部系统 · 安全登录”隐藏状态。


### 登录卡片右上角精修

- 右上角装饰由两个偏移大圆改为贴边双层弧面：外层为更明确的蓝色渐变，内层为半透明浅蓝弧线，更接近确认截图。
- “欢迎登录”与“DataAsk 数问”的字号、字重、行距及副标题颜色按局部截图继续收紧。
- 中央 3D 场景保持上一提交确认的向左倾斜方向，不改整体布局。
